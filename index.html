01これは何か

VirtualLens2 で写真を撮ると、被写界深度（ボケ）がかかります。このギミックは、そのボケている範囲だけを崩します。ピントが合っている被写体には一切かかりません。

崩し方は4種類。細く伸びる、タイル状に割れる、真下に垂れる、横に流れる。強さや粗さは12個のダイヤルで調整できます。

アバターのファイルには手を加えません。prefab を1つ入れるだけで、アップロード時のビルドでのみ組み込まれます。外すときは prefab を消すだけです。

仕組み

VirtualLens2 が持っているピント情報（被写界深度の計算結果）をそのまま受け取り、ボケていると判定された画素にだけグリッチをかけています。どこが壊れるかを決めているのは構図ではなく、そのときのピントです。

色を足したり、別の画像を重ねたりはしていません。撮影中の映像そのものに、リアルタイムで処理が入ります。あとから加工しているのではなく、シャッターを切った時点ですでに壊れた状態で写ります。

03導入のしかた

順番があります

VirtualLens2 を先に入れてください。順番が逆だとシェーダーがエラーになります。

置き場所はどこでも構いません。Assets/ の下であれば、フォルダ整理で何階層ネストしていても自動で追いかけます。あとから移動しても大丈夫です。

① Unity で

  1. Assets/FocusDecayEffect/Focus Decay Effect.prefab を、アバターのどこかにドラッグ＆ドロップする
  2. アップロードする

置く場所はどこでも構いません。アバター直下でも、ボーンの奥でも動きます。名前を変えても構いません。ただし1つのアバターに1つだけにしてください（2つ以上あるとビルド時にエラーで止まります）。

VirtualLens2 側で特別な設定をしていただく必要はありません。

② VRChat の中で

アバターのメニューから VirtualLens2 ▸ Effects ▸ Focus Decay を開き、Smear / Blocks / Drip Down / Drip Across のどれか1つを点けてください。

ここが最初のつまずきどころ

点けるまで写真は何も変わりません。4つとも消灯している状態が「効果オフ」です。ON/OFF のボタンはありません。

VirtualLens2 のモニターには映りません

撮り方のコツ

効果が乗るのは VRChat 標準のカメラ（デフォルトカメラ）の側です。VirtualLens2 のモニターには出ません。

そのため、構図とピントは VirtualLens2 のモニターで合わせ、崩れ方はデフォルトカメラのプレビューで確認するという撮り方になります。2つを見比べながら追い込んでください。

モニターに出ていないからといって効いていないわけではありません。撮れた写真には入っています。

効果は Unity 内では見えません

写真・ストリーミングカメラでのみ描画される仕組みのため、シーンビュー・Play モード・ミラーには何も出ません。アップロードして VRChat 内で撮るまで確認できません。

撮るときに

VirtualLens2 のF 値を下げてください。このギミックはピントが合っていない範囲だけを壊すので、F 値が高いままだと画面全体にピントが合ってしまい、壊れる範囲がありません。F 値が最大まで上がっているとボケ自体が無効になり、効果は出ません。

外しかた

アバターに入れた prefab を削除するだけです。アバター側には何も残りません。パッケージごと消す場合は Assets/FocusDecayEffect フォルダを削除してください。

04メニューの場所

VirtualLens2 のメニューの中に入ります。カメラの設定と並ぶ位置です。

VirtualLens2 ▸ Effects ▸ Focus Decay
 ├ Reset          ← 全部初期値に戻して効果オフ
 ├ Smear
 ├ Blocks
 ├ Drip Down
 ├ Drip Across
 ├ Adjust  ▸      崩れ方の調整（8項目）
 ├ Colour  ▸      色の調整（4項目）
 └ Presets ▸      Load ▸ Load 1-4 ／ Save ▸ Save 1-4
見つからないとき

VirtualLens2 のメニューが項目でいっぱいの場合は、代わりにアバターメニューの一番上に「Focus Decay」が出ます。どちらに出ても動作は同じです。

05エフェクト4種

4つのうち1つを選ぶと ON になります。すべて消灯させると OFF です。

Smear
いろいろな向きに細く伸びます。4つの中で一番おとなしく、写真に馴染みます。
Blocks
タイル状に割れて、中身がずれます。格子が見えるのが持ち味です。Width で、細かいモザイクから大きなタイルまで変わります。
Drip Down
細い列が真下に垂れます。裂け目は画面全体に散らばるので、どこが垂れるかはピントが決めます。
Drip Across
同じものが横に流れます。

06Adjust — 崩れ方

Intensity
効果の強さ。
Drip Down / Drip Across では意味が変わり、「垂れる列の本数」になります。下げると薄くなるのではなく、本数が減って歯抜けになります。
Width
崩れの大きさ。Blocks では 0 で細かいモザイク、1 で大きなタイル。Drip では垂れる列の太さ、Smear では筋の太さです。
Length
崩れの長さ。走りの長さ、垂れの長さです。
Displace
画素をどれだけ引きずるか。初期値の中央が標準で、右に回すと最大2倍まで伸びます。0 にすると絵は動かず、色の変化だけが残ります。
Merge
隣の崩れと引っ張り合って、崩れていない隙間を埋めます。上げるほど効果が広がります。
Speed
崩れ方を1秒に何回抽選し直すか。0 にすると止まり、同じ構図なら何枚撮っても同じ絵になります。写真の中で何かが動くダイヤルではありません。追い込んだ1枚を撮り直したいときは 0 にしてください。
Falloff
どのくらいボケたら最大まで壊すか。下げるほど、浅いボケでも壊れます。
Protect
被写体が背景へコピーされるのを防ぎます。初期値は 0（＝防がない）で、被写体が引きずられて伸びます。像が二重に見えるのが気になるときは上げてください。被写体そのものは、どの値でも壊れません。

07Colour — 色

Chroma
赤と青を、崩れた向きの前後から取ってくる量。輪郭のある場所ほど色がずれて見えます。ボケが深く平坦な場所では変化が小さく出ます。
Posterize
減色の強さ。
Prism
割れた液晶のように、崩れた場所へ原色がまとまって入ります。強い効果です。0.1〜0.3 から試してください（初期値は 0）。
Bleed
色が、裂けた向きに尾を引いて滲みます。Chroma が輪郭の色ズレなのに対して、こちらは流れる滲みです。見た目にはっきり出るのはこちらです。

08Presets と Reset

Presets — 設定を4つまで保存

Save ▸ Save 1 で今の設定を保存し、Load ▸ Load 1 で呼び出します。保存されるのはダイヤル12本と、選んでいるエフェクトの種類です。

Load と Save は別のメニューに分けてあります。撮影中に誤って上書きしないためです。

まだ保存していないスロットを Load すると、初期設定に戻ります。

Reset

ダイヤル12本を初期値に戻し、エフェクトをオフにします。ダイヤルは今の値が画面から読めないので、触りすぎて分からなくなったらここに戻ってきてください。

09思った絵にならないとき

効きが弱い / 崩れる範囲が狭い

上から順に試してください。

  1. VirtualLens2 の F 値を下げる。ピントの合う範囲が狭くなり、崩れる面積そのものが広がります
  2. Falloff を下げる。浅いボケでも最大の強さに届くようになります
  3. Intensity / Length / Displace を上げる
  4. Merge を上げる。崩れていない隙間が埋まります

被写体が二重に写る

Protect を上げてください。初期値は 0 で、被写体が背景へ引きずられる状態です。引きずり自体を演出として使いたい場合は下げたままにします。

同じ絵をもう一度撮りたい

Speed を 0 にしてください。崩れ方の抽選が止まり、同じ構図なら同じ絵になります。

写真が何も変わらない

  • エフェクトを選んでいない（4つとも消灯＝OFF です）
  • F 値が高すぎて、画面全体にピントが合っている
  • F 値が最大まで上がっていて、ボケ自体が無効になっている
  • Unity 内で見ている（Unity では見えません）
  • VirtualLens2 のモニターを見ている（モニターには映りません。デフォルトカメラ側で確認してください）

メニューには出るのに効果が出ない

prefab を、無効になっているオブジェクトの下に置いていませんか。親オブジェクトが有効になっているかご確認ください。

10エラーと対処

ビルド時に出るエラーです。クリックすると対処が開きます。

シェーダーが見つからないか、コンパイルに失敗しています

VirtualLens2 がこのプロジェクトに入っていません。先に導入してください。

入っているのにこのエラーが出る場合は、メニューの Tools ▸ Focus Decay ▸ Locate VirtualLens2 を実行してください。VirtualLens2 を探し直して、シェーダーの参照先を合わせます。

直せない場合は Assets/FocusDecayEffect を削除すれば元に戻ります。

このアバターに VirtualLens2 がセットアップされていません

そのアバターに VirtualLens2 が入っていません。先に導入してください。

VirtualLens2 が Remote Only 構成になっているため、写真を処理する部分がアバターに存在しません

VirtualLens Settings の Remote Only が強制有効になっています。Auto に戻すか、PC 版では Remote Only を使わない設定にしてください。

VirtualLens2 の被写界深度（ボケ）の描画部分が見つかりません

VirtualLens2 のボケ機能が無効になっています。通常は既定で有効です。古い VRChat SDK をお使いの場合、VirtualLens Settings の Aperture に「Enable DoF Simulation」という項目が出ますので、チェックが入っているかご確認ください。

VirtualLens2 の被写界深度まわりの構成が想定と異なります

お使いの VirtualLens2 のバージョンを添えてご連絡ください。対応を検討します。

VirtualLens2 が Destructive モードになっている可能性があります

VirtualLens2 を Apply でシーンに焼く方式で使っています。非破壊モードでご利用ください。

Focus Decay Effect がこのアバターに 2 個入っています

prefab が複数入っています。1つだけにしてください。

Modular Avatar の更新を求めるウィンドウが出る

Modular Avatar 1.18.0 以上が必要です。更新してください。

11制限

  • PC 専用です。Quest / iOS 向けのビルドでは、prefab を入れたまま自動的に無効になります
  • VirtualLens2 の非破壊モード専用です
  • VirtualLens2 の置き場所は自由です（Assets/ の下であればネストしていても追従します）
  • 1つのアバターに1つだけ入れてください
  • 効果は写真とストリーミングカメラにだけ出ます。自分の視界・ミラー・他の人からの見え方は変わりません
  • VirtualLens2 のモニターには映りません。崩れ方の確認はデフォルトカメラのプレビューでおこなってください
同期コストについて

パラメータは 66 本ありますが、すべてローカル専用で、同期コストは 0 bit です（うち 52 本はプリセット4枠の保存用）。他の人には一切送信されません。

12更新のしかた

バージョンを入れ替えるときは、次の順でお願いします。

  1. アバターから Focus Decay Effect を削除
  2. Assets/FocusDecayEffect フォルダごと削除
  3. 新しい .unitypackage をインポート
  4. prefab を入れ直す

ファイルの識別子が変わるため、上書きインポートだけだと参照が切れます。

設定の引き継ぎ

内部のパラメータ名が変わった項目は、更新すると初期値に戻ります。変わった版は更新履歴に明記します。
